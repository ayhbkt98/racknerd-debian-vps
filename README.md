## Debian 12 还是 13？版本怎么选

新部署直接上 Debian 13（trixie），它是当前的 stable；除非有必须依赖老环境的东西，否则没有理由从 12 起步。

支持时间线值得记住：Debian 的 stable 先拿 3 年全量支持，之后由 LTS 团队再续 2 年安全更新，一共约 5 年。目前的 Debian 12（bookworm）已经转入 oldstable，LTS 支持到 2028 年年中；Debian 13 是当前的 stable，正常能一路用到 2030 年前后。简单说：新项目选 13，手上已经有基于 12 调好的环境就继续用 12，2028 年前升级也来得及。

有人担心 stable 里的软件“太老”。bookworm 仓库里是 PostgreSQL 15、nginx 1.22、OpenSSH 9.2 这一档版本——都是先在大量生产环境里被反复打磨过的。对服务器来说，少几个新功能通常无所谓，少几次半夜升级炸掉才是重点。官方仓库有 5.9 万个包，APT 相关的教程资料也最好找。

系统内看版本用 `cat /etc/debian_version`。大版本之间支持原地升级，流程有官方文档照着做即可，动手前先做快照或备份。

## 1GB 内存能干什么？按场景对号入座

Debian 的默认安装比 Ubuntu 轻不少，裸系统常驻占用很低，所以 1GB 内存的年付机比想象中耐用。按场景划条线：

- 博客、静态站、小型 WordPress：1GB 够用，配 Nginx + PHP-FPM 没压力。
- WireGuard 节点、Tor 中继、代理出口：768MB 都绰绰有余，这类服务几乎不占内存。
- 一两个 Docker 容器、监控 agent、小型 API：1GB 可以，记得加个 swap。
- 数据库（PostgreSQL/MariaDB）、Nextcloud 这类全家桶：直接上 2.5GB 或 4GB。内存打满触发 OOM 杀进程，比省那点钱亏多了。

自建邮件服务器要单独提醒：邮局服务对 IP 信誉、反向解析、25 端口政策都很敏感，低价 VPS 的 IP 段可能早上了黑名单。买之前先查一下 IP，别等配好了才发现信发不出去。

## 装好 Debian 之后，先做这五步

机器开通后，SSH 登进去按顺序过一遍，十分钟内能弄完：

1. `apt update && apt upgrade -y`，把系统补丁先打满。
2. 建一个普通用户并加入 sudo 组，日常别用 root 裸奔。
3. 配置 ufw 防火墙，放行 22、80、443，其余默认拒绝。
4. 安装并启用 `unattended-upgrades`，让安全更新自动打上——Debian 服务器能几年不操心的关键就在这一步。
5. 要换版本或重装，直接在 SolusVM 面板里选 Debian 模板操作。

## 常见问题

**促销价续费的时候会涨吗？**
不会。特价年付方案按下单时的价格长期续费，续费价就是首购价。

**Debian 11 还能选吗？**
能选，但只建议为了兼容老项目时用。bullseye 已经是两代之前的版本，支持窗口比 12 和 13 都短，新部署没有选它的理由。

**1GB 内存跑得动 Docker 吗？**
跑得动，KVM 架构对容器没有限制。一两个轻量容器没问题，但容器里再塞数据库就吃力了，那类负载建议 2.5GB 起步。

**机房选哪个好？**
主要给国内用户访问就选美西，洛杉矶、圣何塞延迟相对更低；用户在欧洲就选阿姆斯特丹。拿不准的话，洛杉矶节点用的人多，资料和踩坑经验也最好找。
